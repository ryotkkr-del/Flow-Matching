# 当日の説明と準備

## 30秒で説明する

「最初はランダムなノイズです。再生すると、少しずつ数字になっていきます。
AIは毎回、いまの画像を見て『どの場所を明るく、どの場所を暗くするか』を計算しています。
下の青緑と橙がその指示です。指示の分だけ画像を変えて、また次の指示をもらいます。
スライダーを動かすと、その途中を好きなところで止められます。」

まず再生し、途中で止めて、下の「いまの画像 → AIの指示 → 少し進めた画像」を指す。
専門用語の説明より、同じ一枚の変化を先に見てもらう。

## 来場者に触ってもらう

1. スライダーを戻したり進めたりして、数字が見えてくる時刻を探す。
2. 複数の画像を選び、同じAIでも初期ノイズで結果が変わることを見る。
3. 同じノイズのままステップを20→100に変え、計算の細かさで結果を比較する。
4. 関心があれば「しくみをのぞく」で学習時と生成時の違いを確認する。

ステップ数を増やすことは追加学習ではない。学習済みのAIの指示を、より細かく受け取ること。
同じseed・同じ枚数・同じモデルなら再現する。生成する数字の種類は指定していない。
学習時の直線補間を、展示中の生成経路と同じものとして説明しない。

## 本番前の実機確認

- 配布した試験用モデルを使う場合、その品質でよいか必ず最終PNGを確認する。必要ならColabで継続学習。
- checkpoints/mnist.ptを置き、固定seedでデモを出力。ai.verifyで照合する。
- 展示PCのネットを切ってstart.batで起動し、スライダー・再生・ファイル読込を確認。
- 1枚20stepと4枚100stepを生成し、待ち時間が許容範囲か確認。
- 保存デモで30分以上再生し、CPU温度・ブラウザのメモリ・画面のスリープ設定を確認。
- 同じPCにソース一式、Python環境、checkpoint、デモを残す。復旧時はCtrl+C→start.bat。

この実機確認は利用者側で行う項目。開発環境で実施済みの検証と混同しない。
