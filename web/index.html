BEHIND THE FLOW

ノイズに、次の一歩を教える。

AIは、数字の画像をたくさん見て「いまの画像をどう変えればよいか」を練習します。展示では、ランダムなノイズから出発し、その指示を何度も受け取って数字をつくります。

学習するとき

ノイズと本物の数字をランダムに組にし、その間を直線で結ぶ。その途中の画像を入力し、直線の速度を予測する練習をする。

xₜ = (1 − t)x₀ + tx₁
目標速度 u = x₁ − x₀
L = mean((vθ(xₜ,t) − u)²)
生成するとき

本物の数字は渡さない。いまの画像と時刻からAIが速度を予測し、その速度に沿って少し進む。生成経路は学習時の直線とは異なり、曲がることがある。

dx/dt = vθ(x,t)
xₖ₊₁ = xₖ + (1/N)vθ(xₖ,k/N)
さらに詳しく：画面の数値と注意点

画像は28×28の784次元ベクトル。学習画像は[0,1]から[-1,1]へ正規化し、初期ノイズは標準正規分布。TinyUNetは画像と時刻から784個の速度を予測します。最終時刻では次の更新は存在しないため、内部表示は最後の区間を示します。

画像表示だけ値を[-1,1]に制限します。ODEの計算状態には制限をかけません。スライダーは実際に計算した離散時刻だけを表示します。速度は符号つき、ヒートマップは|v|/Nです。どちらも軌道全体の最大値で色の尺度を固定します。

チェックポイントに重みの移動平均（EMA）が保存されていれば、それを推論に使います。平均するのは学習中のパラメータで、表示画像の合成やアニメーションの補間ではありません。確率経路・速度予測・オイラー法は同じです。

数字の種類は指定しない無条件生成です。計算ステップを増やしても、必ず品質が上がるとは限りません。学習不足はステップ数だけでは解決できません。
